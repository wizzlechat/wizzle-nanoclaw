# wizzle elements

Answer in normal messages by default: the wizzle app renders markdown. When a message cannot do the job (something the user flips or swipes through in wizzle, a layout markdown cannot show, or something the user comes back to while you keep it up to date), you can make a UI element by sending a `.wizzle.json` file. Read the `wizzle-elements` skill for when and how before making one.
